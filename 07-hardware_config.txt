  3) SƠ ĐỒ GPIO TỔNG QUÁT
================================================================================
  GPIO21  -> I2C SDA: MPU6500 + QMC5883 compass
  GPIO22  -> I2C SCL: MPU6500 + QMC5883 compass
  GPIO14  -> SBUS RX từ receiver MC7RE / Microzone, Serial1 RX, inverted
  GPIO16  -> ALT SENSOR / MTF-01P TX vào ESP32 RX, khai báo sẵn
  GPIO17  -> ALT SENSOR / MTF-01P RX từ ESP32 TX, khai báo sẵn
  GPIO32  -> GPS RX nhận từ ESP32 TX
  GPIO34  -> GPS TX vào ESP32 RX, input-only dùng RX OK
  GPIO35  -> ADC đo điện áp pin qua module chia áp 5:1
  GPIO27  -> ESC M1: Top Left  / trước-trái
  GPIO26  -> ESC M2: Bottom Left / sau-trái
  GPIO25  -> ESC M3: Bottom Right / sau-phải
  GPIO33  -> ESC M4: Top Right / trước-phải
  GND     -> GND chung giữa ESP32, ESC, receiver, MPU6500, QMC5883, GPS/MTF, cảm biến áp

  Module tích hợp telemetry/debug:
  - GPS: UART2 38400 8N1, GPS TX -> GPIO34, GPS RX -> GPIO32, GPS_UART_ENABLED=1.
  - MTF-01P: UART0 remap 115200 8N1, MTF TX -> GPIO16, MTF RX -> GPIO17.
  - QMC5883 compass: I2C 0x0D trên GPIO21/GPIO22, chỉ hiển thị/log heading.

  Lưu ý MTF:
  - MTF TX -> ESP32 GPIO16.
  - MTF RX -> ESP32 GPIO17, nối theo code test MTF độc lập.
  - Firmware dùng UART0 remap cho MTF để GPS và MTF chạy đồng thời.
  - Khi MTF dùng UART0, USB Serial Monitor/blackbox runtime bị tắt để tránh gửi rác vào MTF.
  - KHÔNG dùng GPIO33 làm MTF TX trong firmware drone vì GPIO33 là ESC M4.

  Bảng dây ESC:
  +---------+---------+----------------+----------------+----------+
  | Motor   | GPIO    | Vị trí X-frame | Hướng quay code| Prop     |
  +---------+---------+----------------+----------------+----------+
  | M1      | GPIO27  | TL / trước-trái| CCW            | CCW prop |
  | M2      | GPIO26  | BL / sau-trái  | CW             | CW prop  |
  | M3      | GPIO25  | BR / sau-phải  | CCW            | CCW prop |
  | M4      | GPIO33  | TR / trước-phải| CW             | CW prop  |
  +---------+---------+----------------+----------------+----------+

  Hướng quay trên là NHÌN TỪ TRÊN XUỐNG và khớp với MIX_YAW trong code:
  - M1, M3 là CCW -> MIX_YAW = +1
  - M2, M4 là CW  -> MIX_YAW = -1

  Nếu máy lật khi tăng ga:
  1. Tháo cánh trước khi test.
  2. Kiểm tra lại đúng thứ tự M1/M2/M3/M4 theo bảng trên.
  3. Kiểm tra prop CW/CCW đúng chiều tạo lực nâng.
  4. Kiểm tra IMU orientation ở mục 8 trước khi đổi PID.

  5) ESC / PWM OUTPUT
================================================================================
  ESC               : Generic BLDC ESC 30A, PWM chuẩn
  ESC trong ảnh     : ESC 30A/40A cho motor không chổi than, có sẵn jack chuối
  Tương thích ảnh   : pin 3S/4S, motor 2212 800–1200KV và tương đương
  Chọn theo ảnh     : 30A phù hợp motor 930KV/1000KV/1400KV
  Protocol          : PWM servo/ESC thường, KHÔNG phải DSHOT/OneShot
  Tần số PWM         : 400 Hz
  Dải lệnh attach   : 1000–2000 us
  ESC_MIN_US        : 1000 us
  ESC_MAX_US        : 2000 us
  MUC_GA_NGHI       : 1150 us  (idle sau khi ARM)
  GA_KHOI_DONG_MAX  : 1150 us  (chỉ ARM khi throttle <= ngưỡng này)
  GA_HOAT_DONG_MIN  : 1200 us  (dưới mức này: motor idle, reset PID)

  Thứ tự khởi tạo ESC trong setup():
  1. ESP32PWM::allocateTimer(0..3)
  2. dongCo[i].setPeriodHertz(400)
  3. dongCo[i].attach(PIN_ESC[i], 1000, 2000)
  4. dongCo[i].writeMicroseconds(1000)
  5. delay(2000) để ESC nhận min throttle

  Lưu ý cấp nguồn ESC/BEC:
  - Phải nối GND chung.
  - Nếu ESC có BEC 5V, chỉ nên để MỘT dây đỏ BEC cấp 5V cho ESP32/receiver,
    các dây đỏ BEC còn lại nên rút/ cách điện để tránh các BEC đấu song song.
  - Nếu ESC là OPTO không có BEC, cần module buck 5V riêng đủ dòng.

  6) MIXER MOTOR X-FRAME THEO CODE
================================================================================
  ROLL_MIX_DIR      : +1.0
  PITCH_MIX_DIR     : +1.0
  YAW_MIX_DIR       : +1.0

  MIX_ROLL[4]       : {-1, -1, +1, +1}
  MIX_PITCH[4]      : {+1, -1, -1, +1}
  MIX_YAW[4]        : {+1, -1, +1, -1}

  Nghĩa là theo thứ tự M1, M2, M3, M4:
  - Roll correction âm trên bên trái, dương trên bên phải.
  - Pitch correction dương ở phía trước, âm ở phía sau.
  - Yaw correction dương trên motor CCW, âm trên motor CW.

  Giới hạn trộn:
  PID_OUT_LIMIT     : ±380
  MOTOR_CORR_LIMIT  : ±320
  PID_INT_LIMIT     : ±80
  MAX_RATE_DPS      : ±180 deg/s
  GIOI_HAN_GOC      : ±20 deg từ stick Roll/Pitch
  GOC_AN_TOAN       : 45 deg, vượt ngưỡng sẽ cutoff motor và DISARM

================================================================================
  7) PIN / BATTERY & VOLTAGE SENSOR
================================================================================
  Pin hiện tại      : 3S LiPo 2200 mAh 45C XT60
  Pin trong ảnh     : Shangyi 3S 2200mAh 45C, phích cắm T/XT60
  Điện áp đầy       : 12.6 V
  Điện áp danh định : 11.1 V
  Dòng xả lý thuyết : 2.2Ah x 45C ≈ 99A, chỉ xem là tham khảo vì C-rating shop
                       thường lạc quan; kiểm tra sụt áp/nhiệt thực tế khi bay.
  Cảnh báo hiển thị : 10.5 V tương ứng 0% trên web
  Dải % pin code    : 10.5 V -> 0%, 12.6 V -> 100%
  Pin yếu tự hạ cánh: PIN_YEU_V = 10.8 V
  Pin cạn chặn ARM  : PIN_CAN_V = 10.5 V
  Tốc độ hạ ga auto : HA_CANH_GIAM_US_S = 30 us/giây
  DISARM sau idle   : HA_CANH_IDLE_MS = 3000 ms

  Hành vi failsafe pin:
  - Khi đang ARM và điện áp <= 10.8 V, firmware bật tuDongHaCanh.
  - Auto landing hạ trần ga từ từ, vẫn giữ PID cân bằng Roll/Pitch/Yaw.
  - Người lái có thể kéo ga thấp hơn, nhưng không tăng vượt trần hạ cánh.
  - Khi trần ga xuống vùng idle, firmware chờ 3 giây rồi tự DISARM.
  - Khi điện áp <= 10.5 V hoặc cảm biến pin không đọc được, firmware không cho ARM.

  Cảm biến áp       : Module đo DC 0–25V, chia áp danh định 5:1
  GPIO ADC          : GPIO35 / ADC1_CH7 / input-only
  Hệ số code        : heSoPin = 5.0 mặc định, lưu bằng NVS key "hSPin"
  Cách đọc          : lấy trung bình 32 mẫu analogReadMilliVolts(GPIO35)
  Lọc điện áp        : dienApPin = old*0.85 + new*0.15
  Công thức code    : Vbat = ADC_mV / 1000 * heSoPin

  Cảnh báo 4S:
  - Module 5:1 với 4S đầy 16.8V cho ra khoảng 3.36V.
  - GPIO ESP32 không chịu 5V và ADC thực tế không nên bị kéo quá 3.3V.
  - Muốn dùng 4S phải đổi tỉ lệ chia áp, đo lại bằng đồng hồ và chỉnh heSoPin.

================================================================================
  8) IMU MPU6500 / GY-6500
================================================================================
  Chip              : MPU6500 6DOF
  Module trong ảnh  : GY-6500 / MPU6500 IMU 6DOF
  Loại cảm biến     : 3-axis accelerometer + 3-axis gyroscope
  Độ phân giải      : 16-bit
  Nguồn module ảnh  : 3.3V–5VDC
  Logic I2C ảnh     : 3.3VDC, module có sẵn pull-up I2C lên 3.3V
  Header ảnh        : chuẩn 2.54 mm
  Kích thước ảnh    : khoảng 15 x 25 mm
  I2C address       : 0x68 khi AD0=GND
  WHO_AM_I expected : 0x70
  Bus I2C           : SDA GPIO21, SCL GPIO22, 400 kHz
  Driver            : mpu6500_driver.cpp / mpu6500_driver.h

  Cấu hình thanh ghi theo driver:
  - Reset chip                 : PWR_MGMT_1 = 0x80, delay 100 ms
  - Clock PLL gyro             : PWR_MGMT_1 = 0x01
  - Sample rate                : SMPLRT_DIV = 0x03 -> 1000/(1+3)=250 Hz
  - Gyro DLPF                  : CONFIG = 0x04, xấp xỉ 20 Hz
  - Gyro full-scale            : GYRO_CONFIG = 0x08 -> ±500 deg/s
  - Gyro scale                 : 65.5 LSB/(deg/s)
  - Accel full-scale           : ACCEL_CONFIG = 0x08 -> ±4 g
  - Accel scale                : 8192 LSB/g
  - Accel DLPF                 : ACCEL_CONFIG2 = 0x04, xấp xỉ 20 Hz
  - Burst read                 : 14 byte từ ACCEL_XOUT_H

  Hiệu chuẩn:
  - CALIB_SAMPLES              : 500 mẫu
  - Khi khởi động, firmware tự gọi mpu.calibrate()
  - Driver hiện chỉ tính gyro bias; accel offset trong driver được reset về 0.
  - Cân bằng level dùng rollOffset/pitchOffset lưu qua web/NVS.

  Bộ lọc trong driver:
  - Accel LPF trước atan2       : alpha = 0.05
  - Complementary filter        : alpha = 0.98 gyro + 0.02 accel
  - Yaw                         : tích phân gyro Z, giữ trong [-180, +180]

  Orientation đang dùng trong firmware:
  IMU_SWAP_ROLL_PITCH          : 1
  IMU_ROLL_SIGN                : -1.0
  IMU_PITCH_SIGN               : +1.0
  IMU_YAW_SIGN                 : +1.0
  IMU_RATE_ROLL_SIGN           : -1.0
  IMU_RATE_PITCH_SIGN          : +1.0
  IMU_RATE_YAW_SIGN            : +1.0

  Diễn giải:
  - Firmware đang hoán đổi roll/pitch từ driver để khớp cách gắn IMU thực tế.
  - Roll angle dùng d.angle.pitch rồi nhân -1.
  - Pitch angle dùng d.angle.roll rồi nhân +1.
  - Roll rate dùng d.gy rồi nhân -1.
  - Pitch rate dùng d.gx rồi nhân +1.
  - Nếu đổi chiều gắn FC/MPU, phải sửa nhóm IMU_* trước khi tune PID.

================================================================================
  10) RC RECEIVER / SBUS
================================================================================
  TX                : Microzone MC6C hoặc tay tương thích 6 kênh
  TX ảnh/PDF        : Microzone 6C-MINI, 6 kênh, 2.4GHz FHSS
  RX                : MC7RE / MC7RE-V2 hoặc receiver xuất SBUS
  RX PDF            : MC7RE-V2, 7 PWM signals + 1 SBUS signal
  UART              : Serial2
  Baud              : 100000
  Format            : SERIAL_8E2
  Inverted          : true
  RX pin            : GPIO14
  TX pin            : -1, không dùng
  Frame size        : 25 byte
  Start byte        : 0x0F
  Chu kỳ frame PDF  : 14 ms/frame
  Mức tín hiệu PDF  : SBUS/PWM high level 3.3V
  Raw map           : 172–1811 -> 1000–2000 us
  Timeout failsafe  : 1000 ms không có frame -> matTinHieu = true, SBUS OFF
  Lost frame flag   : buf[23] bit 2 -> SBUS OFF
  Failsafe flag     : buf[23] bit 3 -> matTinHieu
  Mức sóng tay cầm  : chất lượng frame SBUS, không phải RSSI RF thật của receiver

  Thông số Microzone từ ảnh/PDF:
  - TX tần số                 : 2401–2478 MHz
  - TX công suất              : <= 100 mW
  - TX nguồn                  : DC 4.5–9V, dùng 4 pin AA hoặc 2S LiPo
  - RX nguồn                  : DC 4.5–6V
  - Khoảng cách điều khiển    : ảnh ghi 300–800 m; PDF ghi >800 m
  - RX failsafe mặc định      : CH1/CH2/CH4 = 1500 us, CH3 = 900 us,
                                các kênh khác giữ nguyên
  - PWM RX                    : 1000–2000 us khi không mix; 880–2120 us khi mix/trim

  Lưu ý SBUS:
  - Manual MC7RE ghi SBUS cần đảo mức tín hiệu. Firmware ESP32 đang dùng tham số
    inversion=true trong Serial2.begin(). Nếu thực tế không đọc được SBUS, cần thêm
    mạch đảo mức hoặc kiểm tra đúng chân/pad SBUS của receiver.

  Channel map theo code:
  CH1  -> Roll stick
  CH2  -> Pitch stick
  CH3  -> Throttle / ga
  CH4  -> ARM/DISARM gesture
  CH5  -> AUX1, hiển thị web
  CH6  -> AUX2, hiển thị web

  ARM/DISARM bằng CH4:
  - ARM    : CH4 > 1750 giữ > 3 giây
  - DISARM : CH4 < 1250 giữ > 1 giây

  Điều kiện cho phép ARM:
  - MPU6500 OK
  - SBUS OK
  - Không mất tín hiệu
  - CH3 throttle <= 1150
  - |roll| <= 10 deg và |pitch| <= 10 deg

  15) TRÌNH TỰ SETUP THEO CODE
================================================================================
  1. Tắt brownout detector.
  2. Serial.begin(115200).
  3. Tạo mutex.
  4. Nạp cấu hình NVS và set notch filter.
  5. Khởi tạo MPU6500 trên I2C 21/22, calibrate gyro 500 mẫu.
  6. Wire.setTimeOut(20).
  7. Khởi tạo QMC5883 tại 0x0D, nếu không thấy thì scan I2C và báo FAIL.
  8. Serial1.begin(100000, SERIAL_8E2, GPIO14, -1, true) cho SBUS.
  9. GPS UART2 begin 38400 8N1, RX GPIO34, TX GPIO32.
  10. MTF-01P UART0 begin 115200 8N1, RX GPIO16, TX GPIO17.
 11. Đọc điện áp pin lần đầu.
 12. Khởi tạo WiFi AP.
 13. Khởi tạo web server.
 14. Allocate LEDC timers 0..3.
 15. Attach 4 ESC 400Hz, 1000–2000us, ghi 1000us.
 16. Delay 2000ms cho ESC.
 17. Tạo taskFlight trên core 1, taskComm trên core 0.
 18. loop() tự xóa.
